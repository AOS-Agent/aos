# v0.7.8 — the system stops crying wolf

**Status: ready when the operator says so.** Patch on top of v0.7.7, cut the
same day, from the nine GitHub issues the 0.7.7 issue sweep found were touched
but not fixed. All test-first; nothing here restructures the instance except
migration 133.

| Issue | Root cause (file) | Fix |
|---|---|---|
| #2357 | `voice_transcriber.py` hardcoded `timeout=120`; `_handle_voice` echoed transcripts in one >4,096-char message | timeout = `min(1200, max(120, 3×duration))`; transcript chunked; a failed echo is logged, never fatal |
| #2324 | `heartbeat.py` dedupe was an in-memory local — reset on each of 3,234 restarts | `notice_state` table in `bridge.db`, 6-hour TTL |
| #2356 | scheduler compared `kern.boottime` as an exact string; freshness window never enforced | ±120 s tolerance, 10-minute fresh window, boot-second persisted; **migration 133** removes the `.last-boot`-as-directory workaround |
| #2354 | watchdog: ICMP ping, no debounce, text-parsed `tailscale status --self` | two HTTPS probes, alert after 2 consecutive failed ticks, `tailscale status --json` |
| #2345 | `deployment_health` appended "fixed" without verifying | fix() re-runs check(); FIXED only when the condition cleared; `qmd collection show` as the oracle |
| #2343 | `volume_access` hardcoded `/Volumes/AOS-X` | reads `config/storage.yaml`'s `data_drive`; OK when none is configured |
| #2346 | `instance_hygiene` globbed `com.aos.*` only, and called anything unmanifested an orphan | only `com.aos.*`/`com.agent.*` are candidates; `preserved-services.yaml` honoured; foreign LaunchAgents never listed |
| #2347 | `check-update` wrote `last_apply: ok` whenever no step failed; no downgrade check | `noop` when VERSION/hash did not move; `refused_downgrade` + one notice; `--allow-downgrade` is the only override |
| #2320 | `daily_briefing.py`, `session_manager.py`, `friction-rules`, `intent_classifier.py` wrote state under `~/aos` | all state under `~/.aos/data/bridge/`, resolved per call |
